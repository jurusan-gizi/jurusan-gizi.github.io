# Gizi-Link – tampilan baru (menu kiri + Beranda profil prodi)

Hanya GitHub yang diubah. Apps Script portal dan sheet TIDAK perlu disentuh.

## Pasang
Di repo `jurusan-gizi.github.io` (portal Gizi-Link):
1. Ganti: `index.html`, `app.js`, `style.css`
2. Tambah file baru: `profil-prodi.js`
3. Tunggu ±1–2 menit, buka https://jurusan-gizi.github.io lalu muat ulang (Ctrl+Shift+R di laptop).

Jangan ubah `config.js` dan `sso.js` (tetap pakai yang ada).

## Mengubah isi Beranda (visi, misi, profil lulusan, CPL, akreditasi)
Buka `profil-prodi.js` di GitHub → ikon pensil → ubah teksnya → Commit.
Petunjuk singkat ada di bagian atas file itu.

## Kalau ingin kembali ke tampilan lama
GitHub menyimpan riwayat: buka file → History → pilih versi sebelum perubahan → salin kembali.
